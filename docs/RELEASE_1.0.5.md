# 윤DF 1.0.5 · Pretendard와 문서 탭

2026-09-30 · 기준 버전 1.0.4. Windows 10/11 x64 설치 EXE와 소스 ZIP 제공.

## 변경

- 앱 UI에 Pretendard 1.3.9 Regular/Medium/SemiBold/Bold 정적 TTF를 포함했다. 시스템에 글꼴을 설치하거나 인터넷에 연결할 필요가 없다.
- Qt 애플리케이션 기본 서체와 QML UI 서체를 통일했다. 작은 글자는 플랫폼 네이티브 렌더링과 수직 힌팅을 사용한다. Qt 6의 고해상도 처리를 사용하며 화면 배율을 글자 크기에 중복 적용하지 않는다.
- 일반 UI 기본값 15px, 주요 버튼과 탭 14px, 보조 글씨 12–13px. 주요 버튼 높이 38px, 작은 버튼 34px, 상단 도구 모음 56px, 문서 탭 48px.
- 떠 있는 제목 버튼을 경계가 있는 문서 탭으로 바꿨다. 활성 탭은 흰 도구 모음과 연결되고 가는 파란 선으로 구분된다. 긴 이름 줄임, 닫기, 이름 변경, 드래그 순서 변경, 열린 문서 목록을 유지했다.
- 1000px 폭에서 도구 모음 오른쪽 버튼이 잘리는 문제를 수정했다. 좁은 창에서는 버튼 간격과 모드 버튼 폭을 조절한다.
- 승인한 파란 문서형 윤DF 아이콘 유지. 사이드바 미리보기에는 이동·확대·페이드 전환이 없다.
- PDF 본문과 편집기의 원본 글꼴 처리에는 UI 서체를 강제하지 않는다. Windows 시스템 제목 표시줄과 운영체제 소유 파일 선택 창의 서체는 Windows 설정을 따른다.

## 검증

Linux / CPython 3.12 / PySide6 6.8.3 / Qt offscreen software 환경에서:

- 단위·통합 94개 통과.
- 기존 UI 회귀 21개 묶음 최종 통과. 열기, 탭 격리·순서·닫기·이름 변경, 읽기·검색, 본문 편집·저장·재열기, 이미지·페이지 편집, 주석, OCR, 인쇄 미리보기, 복구, 업그레이드 모의 시험 포함.
- 새 글꼴 시험: 100/125/150/200% 배율에서 각 1000×640, 1320×900 창을 검사. 4개 굵기의 한글 글리프, 실제 UI 글꼴 객체 97개, 버튼 경계, 밝게·어둡게, 설정 창 및 긴 한글 문서명 확인.
- 기존 UI 시험의 고정 드래그 좌표가 커진 헤더와 맞지 않아 실제 썸네일 위치에서 좌표를 계산하도록 수정했다. OCR 시험은 실제 실행기처럼 프로젝트 루트에서 실행하고 페이지 이동 완료를 기다린다. 초회 실패와 최종 결과를 함께 보관한다.
- 실행기 2종은 x64 GUI PE이며 제품 버전 1.0.5와 승인된 ICO를 포함한다. Windows 런타임 8개 고정 입력의 SHA-256을 원본 매니페스트와 대조했다.

## 확인 범위

실제 Windows 설치·업데이트·삭제, 실제 모니터 이동/DPI 전환, Windows GPU·ClearType·한글 IME, 실제 프린터는 이 Linux 환경에서 실행 검증하지 않았다. 배율별 캡처는 Linux 소프트웨어 렌더링 결과다. 모든 종류의 PDF에 버그가 없음을 보장하는 결과는 아니다.
