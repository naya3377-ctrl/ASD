# 윤DF 1.0.7 · 미리보기 선택 표시

2026-09-30 · 기준 버전 1.0.6

- 문서를 열 때 페이지가 자동으로 선택되지 않는다. 현재 읽는 페이지는 작은 파란 마커로만 표시한다.
- 페이지 번호 입력·읽던 위치 복원·페이지 이동은 읽는 위치만 변경한다. 명시적으로 선택한 페이지와 현재 읽는 위치를 분리한다.
- 미리보기를 클릭하면 그 종이 영역에만 사각 테두리를 표시한다. 종이 밖의 파란 배경과 큰 둥근 테두리는 제거했다. 선택 테두리는 실제 종이 크기와 좌표가 일치하는 별도 오버레이이며 이미지 위에 그린다.
- Ctrl/Shift 다중 선택과 드래그 순서 변경은 유지한다. Ctrl+클릭으로 마지막 선택을 해제한 뒤 문서 상태가 갱신되어도 자동 선택이 다시 생기지 않는다.
- 선택이 없을 때 회전·삭제 등 기존 페이지 명령은 현재 페이지를 대상으로 하는 기존 동작을 유지한다.
- 미리보기에 이동·확대·페이드 애니메이션을 추가하지 않았다. 1.0.6의 Pretendard 렌더링 수정도 유지했다.

검증: Linux Qt software에서 94개 단위·통합 테스트와 22개 UI 회귀 묶음 통과. 새 문서 무선택, 일반 페이지 이동 무선택, 클릭 후 종이 크기의 테두리, 선택과 읽는 위치의 독립성, 선택 해제 후 상태 갱신, 썸네일 무전환을 검사했다. Ctrl 다중 선택·드래그 재배치·저장·재열기 등의 기존 회귀도 통과했다. 화면은 screenshots, 상세 결과는 qa에 포함했다.

Windows x64 실행기와 오프라인 설치 파일을 교차 빌드한다. 실제 Windows 설치·실행은 이 환경에서 검증하지 않았다.
