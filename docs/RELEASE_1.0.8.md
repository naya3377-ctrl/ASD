# 윤DF 1.0.8 · 글자에 붙는 메모와 편집 화면 안정화

2026-09-30 · 기준 버전 1.0.7

## 사용자 보고와 수정

- **글자에 단 메모가 아이콘으로만 표시되던 문제.** 글자를 선택하고 메모를 쓰면 페이지 위 메모 아이콘이 따로 생겼다. 이제 선택한 글자가 메모를 담은 형광펜 주석이 된다. Acrobat의 "텍스트에 메모 추가"와 같은 PDF 표준 방식이며, 다른 PDF 프로그램에서도 그 글자에 붙은 메모로 보인다. 주석 목록에는 "메모"로 표시되고 선택한 글자를 인용한다.
- **기존 표시에 메모 달기.** 형광펜·밑줄·취소선 위에서 오른쪽 클릭하면 "이 표시에 메모 달기" 또는 "메모 수정"이 나온다. 표시를 더블클릭해도 메모가 열린다. 별도 아이콘을 만들지 않고 그 표시 자체에 내용을 저장한다.
- **오른쪽 클릭 메뉴.** 상황에 따라 "이 표시에 메모 달기 / 선택한 글자에 메모 달기 / 여기에 메모 추가"로 바뀐다.
- **메모 아이콘 교체.** 노란 상자에 검은 말풍선이 들어 있던 기본 아이콘을, 메모 색으로 채운 둥근 말풍선과 점 세 개로 바꿨다. 아이콘 모양은 PDF 안의 표시 정보(appearance)로 저장하므로 저장 후 다시 열거나 다른 프로그램에서 열어도 유지된다. 이동하거나 색을 바꿔도 유지된다. 다른 프로그램이 만든 메모와 그 아이콘은 바꾸지 않는다.
- **본문 편집 시 화면이 튀던 문제.** 문단을 누르면 도구 모음 아래에 편집 막대(약 50px)가 새로 생기면서 페이지가 아래로 밀렸다. 그래서 누른 자리와 화면이 어긋났다. 이제 편집 막대는 "본문 수정"이나 "글자 추가" 도구를 고르는 순간부터 자리를 잡는다. 글꼴 경고처럼 나중에 생기는 줄이 있어도 같은 높이만큼 스크롤을 보정해서 포인터 아래 페이지가 움직이지 않는다.

## 안정성

- 앱 UI 글꼴(Pretendard) 파일이 손상되거나 보안 프로그램에 막혀도 앱이 시작되지 않던 경로를 막았다. 진단 기록에 남긴 뒤 시스템 글꼴로 대체한다.
- PDF 결합·본문 편집 결과에 기록하는 제작 프로그램 버전을 코드의 버전 번호 하나에서 가져오게 했다.
- UI 글꼴 시험(qa_typography)이 이 환경에서 종료 중에 가끔 비정상 종료했다. 앱의 실제 종료 방식처럼 QML 엔진을 즉시 정리하도록 시험을 고쳤고 8회 연속 통과했다.

## 검증

Linux / CPython 3.12 / PySide6 6.8.3 / Qt offscreen software 환경에서:

- 단위·통합 98개 통과(메모 아이콘 저장·이동·색 변경, 글자 메모, UI 글꼴 대체 시험 추가).
- UI 회귀 23개 묶음 통과. 새 시험 `qa_edit_stability.py`는 스크롤된 페이지에서 문단 클릭, 늦게 생기는 경고 줄, 편집 종료 뒤에도 포인터 아래 위치가 1px 이내로 유지되는지와 글자 메모·기존 표시 메모·위치 메모를 실제 화면 조작으로 검사한다.

Windows 실제 설치·실행과 Acrobat에서의 표시는 이 환경에서 검증하지 않았다.
