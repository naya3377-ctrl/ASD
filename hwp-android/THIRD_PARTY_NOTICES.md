# 사용한 오픈소스

## hwplib
- https://github.com/neolord0/hwplib (kr.dogfoot:hwplib 1.1.11)
- Apache License 2.0
- hwp 파일 읽기·쓰기. 안에 Apache POI(POIFS, Apache License 2.0) 일부가 들어 있습니다.

## hwpxlib
- https://github.com/neolord0/hwpxlib (kr.dogfoot:hwpxlib 1.0.9)
- Apache License 2.0
- hwpx 파일 읽기·쓰기.

## Material Icons
- https://github.com/google/material-design-icons
- Apache License 2.0
- 앱 단추 아이콘(뒤로, 편집, 저장, 찾기 등)의 도형 데이터.

## 시험·서식 문서
- `core/src/test/resources/samples/*.hwp`, `app/src/main/assets/blank.hwp`: hwplib 저장소의 `sample_hwp` (Apache License 2.0).
  `blank.hwp`는 작성자 정보를 지운 뒤 새 문서 서식으로 씁니다.
- `core/src/test/resources/samples/*.hwpx`: hwpxlib 저장소의 `testFile` (Apache License 2.0).
