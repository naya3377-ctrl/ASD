# HWP 편집기 (안드로이드)

안드로이드 휴대폰에서 한글 문서(.hwp, .hwpx)를 열어 읽고, 글을 고쳐 저장하는 앱입니다.
**0.1.0 · 첫 시험판.** 실제 휴대폰에서는 아직 확인하지 못했습니다(자동 시험만 통과).

## 할 수 있는 것

- hwp(한글 2002 이후의 5.0 형식), hwpx 문서 열기
  - 파일 관리자·카카오톡·메일에서 "다른 앱으로 열기"나 "공유"로도 열 수 있어요.
- 본문, 표 칸, 글상자, 머리말·꼬리말, 각주·미주, 표·그림 캡션의 글 고치기
  - Enter로 문단 나누기, 지워서 문단 합치기, 탭, 줄바꿈(문단 안)도 그대로 저장돼요.
- 저장 / 다른 이름으로 저장, 새 문서 만들기(hwp)
- 찾기, 되돌리기·다시 하기, 글자 크기 바꾸기, 공유
- 그림·표·도형·수식·누름틀 같은 개체는 고치지 않아도 문서에 그대로 남아요.

## 저장할 때 지키는 것

1. **고친 문단만 새로 씁니다.** 손대지 않은 문단은 원래 모습 그대로입니다.
2. 고친 문단 안에서도 **남은 글자는 원래 글자 모양**(글꼴·크기·굵게·색)을 지킵니다.
   새로 친 글자는 바로 앞 글자의 모양을 따릅니다.
3. 보이지 않는 개체(구역 설정, 표, 그림, 누름틀 표시, 책갈피 등)는 **절대 지우지 않습니다.**
   주변 글을 지우면 가까운 자리로 옮겨 둡니다.
4. 저장 파일을 만든 뒤 **다시 읽어서** 글이 의도대로 들어갔는지, 표·그림 수가 그대로인지
   확인하고, 통과했을 때만 원래 파일에 씁니다. 쓴 뒤에도 한 번 더 읽어 비교합니다.

## 아직 못 하는 것

- 굵게·색 같은 글자 모양 바꾸기, 표·그림 넣기·지우기, 표 칸 합치기
- 한글과 똑같은 쪽 모양 보기 — 휴대폰에서 읽기 좋게 글을 다시 배치해서 보여 줍니다.
- 암호가 걸린 문서, 배포용 문서 저장(읽기만 가능), 한글 97 이전(3.0) 형식
- WMF/EMF 같은 일부 그림 형식은 미리보기 없이 자리만 표시합니다(파일에는 남아요).

## 설치(시험판)

1. GitHub 저장소의 **Actions → Android build (HWP 편집기)** 에서 가장 최근 성공한 실행을 엽니다.
2. 아래쪽 **Artifacts** 의 `HWP-Editor-APK` 를 내려받아 압축을 풀면 `HWP-Editor-0.1.0.apk` 가 나옵니다.
3. 휴대폰에서 APK를 열고 "출처를 알 수 없는 앱 설치"를 허용해 설치합니다.

모든 빌드가 같은 서명 키(`app/debug.keystore`)를 쓰므로, 새 버전을 기존 앱 위에 덮어 설치할 수 있어요.
이 키는 시험용 공개 키입니다. 앱 마켓에 올릴 때는 따로 비공개 키를 만들어야 합니다.

## 구조

```
hwp-android/
  core/   문서 처리 엔진 (안드로이드와 무관한 Kotlin/JVM)
          - HwpDocuments: 열기·저장의 입구, 저장 결과 재확인
          - hwp/HwpAdapter, hwpx/HwpxAdapter: 형식별 읽기·쓰기 (hwplib, hwpxlib 사용)
          - edit/FlowRebuilder: 고치기 전·후 글을 비교해 문단을 다시 만듦(글자 모양·개체 보존)
          - edit/TextDiff: 글 비교(Myers 알고리즘)
          - hwpx/HwpxPackage: hwpx 압축 정리(mimetype, 빠진 파일 복구, 미리보기 글)
  app/    안드로이드 화면 (프레임워크 뷰만 사용, AndroidX 없음)
          - MainActivity: 시작 화면 · EditorActivity: 문서 화면 · AboutActivity: 앱 정보
          - ui/DocumentRenderer: 문서 모델 → 화면, ui/TableGridView: 표 배치
          - ui/FlowEditText: 문단 묶음 입력칸, ui/UndoManager: 되돌리기
```

## 개발

```sh
# 문서 처리 엔진만 (안드로이드 SDK 없이)
./gradlew -PcoreOnly :core:test

# 실제 문서 폴더로 대량 시험 (열기 → 모든 글에 덧붙이기 → 저장 → 다시 읽어 확인)
./gradlew -PcoreOnly :core:test --tests '*BulkFilesTest*' -Dhwp.bulkDir=/문서/폴더

# 전체 (안드로이드 SDK 필요)
./gradlew :core:test :app:testDebugUnitTest :app:assembleRelease
```

시험 결과 파일(저장본)은 `core/build/test-output/` 에 남습니다.

## 시험 현황

- 엔진 시험 24개: 열기, 저장 후 재확인, 문단 나누기·합치기·지우기, 글자 모양 보존,
  특수 문자(탭·줄바꿈·묶음 빈칸·이모지), 표 칸·캡션, 누름틀, 반복 저장, hwpx 압축 규칙.
- 실제 문서 93개 대량 시험(hwplib·hwpxlib 저장소의 시험 문서): 91개 통과,
  배포용 문서 1개는 읽기 전용 처리, 1개는 hwpxlib 1.0.9가 열지 못하는 문서(최신 개발판에서는 열림).
- 저장한 hwp 파일 25개를 독립 해석기(pyhwp)로 모든 레코드 해석 확인.
- 한컴오피스 실물로 연 확인은 아직 못 했습니다.
